# MVP Guide

A LLM deve atuar como Product Designer e Senior Front-end.

## Regras

-   Não construir tudo de uma vez.
-   Sempre concluir uma etapa antes da próxima.
-   Explicar decisões de UX.
-   Priorizar código limpo e escalável.

## Ordem de desenvolvimento

### Sprint 1

-   Setup do projeto
-   Design tokens
-   Layout base
-   Navegação

### Sprint 2

-   Landing
-   Lista de serviços
-   Galeria

### Sprint 3

-   Fluxo de agendamento
-   Calendário
-   Horários

### Sprint 4

-   Resumo
-   Pagamento
-   Confirmação

### Sprint 5

-   Área da cliente

### Sprint 6

-   Dashboard da profissional

Ao final de cada sprint, aguarde aprovação antes de continuar.
